## Проверка воспроизводимости

1. Сверить SHA-256 или аналог манифеста для кода версии 2.1.0.
2. Создать чистое виртуальное окружение по `requirements.txt`; убедиться, что команды в README актуальны.
3. Выполнить тесты: по финальному отчёту прошли **16 тестов**; проверить фактическое число в опубликованном коммите.
4. Повторить парный расчёт для одного базового сценария (FCFS и OPTIMIZED) через `result_adapter.run_scenario(...)`; сравнить метрики и проверить схему JSON.
5. При наличии ресурсов повторить все 114 парных сценариев. Для каждого сохранить входной scenario_id, seed/config, версию ядра и выходные JSON/CSV.
6. Аудит: 228 итоговых расписаний должны иметь **0 выявленных нарушений внутри математической модели**.
7. Проверить, что при изменении параметров интерфейс действительно вызывает расчёт для новых входов либо подписывает результаты как заранее вычисленные.

- Сохранить паспорт на **2–3 страницах** после финальных изменений в Word.
- Уточнить и подтвердить роли участников.
