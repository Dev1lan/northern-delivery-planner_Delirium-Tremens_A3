# Контроль критичных грузов

Критичные категории здесь — условные `food` и `food_extended`; список может задаваться пользователем. Сравнение использует исторические 114 пар синтетических сценариев версии 2.1.0. Это не данные реальных перевозок.

| Категория | Снижение общего тоннажа, сценариев | Снижение тоннажа вовремя, сценариев | Среднее изменение общего тоннажа, т |
|---|---:|---:|---:|
| food | 57 | 0 | -21.648 |
| food_extended | 4 | 0 | -1.956 |

Отрицательное изменение — предупреждение: основной критерий не гарантирует приоритет продовольствия. Для новых расчётов `critical_cargo.py` сравнивает проверенные результаты FCFS и OPTIMIZED и возвращает отдельный массив `warnings`. Если категории нет в заявках, возвращается `not_present`, а не утверждение о равенстве доставок.
