# Среда проверенного запуска

- Windows, Python 3.12.14 (CPython), pip 26.2.2.
- Непосредственный валидатор схемы: jsonschema 4.25.1; зависимости и проверенные версии закреплены в `requirements.txt`.
- Тестовый запуск: `python -m unittest discover -s tests -p "test*.py" -v`.
- Демонстрационный пересчёт: `python -m experiments.demo_check`.
- На других ОС/версиях Python совместимость необходимо подтвердить повторным запуском тестов; численные и временные параметры демонстрации искусственные.

Исходный снимок `release_2.1.0` и его `ALGORITHM_VERSION.json` в полном локальном проекте относятся к историческим файлам. В рабочем коде добавлены входная проверка и ошибка при отсутствии условий; поэтому хэш всего рабочего файла отличается, хотя тест `test_algorithm_invariants.py` проверяет неизменность самой эвристики и цели.
