## Изменение флота

Варианты рассчитаны на `r1_baseline_central_central` с тем же спросом, условиями и требованием. Характеристики добавленных ресурсов взяты из модельного сухогрузного состава `U_DRY_1`. За один опыт изменялись только физические ресурсы. Проверены все четыре стратегии на пяти вариантах флота, 20 расписаний без нарушений.

| Добавить баржу | 0 | 0 | 0 | −12,376 | 0 |
| Добавить буксир | 0 | 0 | 0 | −12,376 | 0 |
| Добавить независимый состав | +4 376,533 | +4 376,533 | 0 | +0,485 | +27 |
| Убрать состав U_DRY_1 | −4 403,611 | −4 403,611 | 0 | −1,011 | −27 |

Таблица показывает SOCIAL_PRIORITY относительно исходного флота. Добавленная баржа делит буксир с имеющимся составом, а добавленный буксир делит баржу. Они не создают ещё один одновременный рейс в этом опыте. При добавлении одного ресурса меняется знаменатель загрузки, даже если число рейсов осталось прежним. Тарифы для этого расчёта не предоставлялись.
