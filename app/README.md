# Веб-приложение планировщика

Интерфейс «загрузил сценарий — увидел маршрут»: проверка входов, мгновенный прогноз нейросети, расчёт расписания матмоделью и карта с графом маршрута, рейсами и нагрузкой.

> Исследовательский прототип на синтетических данных. Это не система управления судоходством.

## Запуск

Из корня репозитория:

```bash
pip install -r requirements.txt -r app/requirements.txt
pip install -r ml/requirements.txt        # по желанию: прогноз ML
python app/server.py                      # http://127.0.0.1:8000
```

Документация API открывается по адресу `/docs`.

## Как пользоваться

1. **Готовый сценарий** — выбрать из списка и нажать «Рассчитать».
2. **Свой сценарий** — перетащить файлы в область загрузки. Файлы распознаются по содержимому, имена могут быть любыми:
   - `cargo.csv`, `units.csv`, `conditions.csv` — обязательны, формат описан в `docs/SCENARIO_INPUTS.md` и `docs/data_dictionary.md`;
   - `config.json` — маршрут (участки), сроки навигации и параметры; без него берётся `scenario_config.json` (Нижнеянск — Усть-Куйга);
   - файл геометрии — линия маршрута для карты, как `map/geo/yana_route.json`; без него маршрут рисуется схемой.
   Примеры файлов скачиваются по ссылкам под областью загрузки.
3. Сразу после проверки открывается предварительный вид: маршрут, глубины, спрос и прогноз нейросети по каждой стратегии (доля в срок с интервалом). Когда матмодель досчитает, он сам заменяется точным результатом: рейсы, суда, сравнение стратегий и расхождение прогноза с расчётом.
4. В карточке «Составы на выбранный момент» и на карте виден статус каждого состава: погрузка, идёт с грузом, выгрузка, возвращается порожним, свободен. Для каждого показаны груз, место, время конца этапа и успевает ли груз к сроку.
5. Пока идёт расчёт, под верхней панелью показывается полоса хода. После расчёта в кнопке «Скачать» — ссылки скачивания результата каждой стратегии в формате контракта 1.0.0.

## Что происходит на сервере

| Шаг | Кто делает | Время |
|---|---|---|
| Проверка входов | матмодель (`optimizer.load` → `scenario_validation`) | миллисекунды |
| Прогноз доли в срок с интервалом | ML-модуль (`ml/predict.py`) | десятки миллисекунд |
| Расписание по трём стратегиям и выбор лучшей | матмодель (`result_adapter.run_scenario`) в отдельном процессе | секунды — минуты |
| Проверка результата | `result.schema.json` | миллисекунды |

Лучшая стратегия определяется сравнением рассчитанных результатов по целевой функции матмодели, а не нейросетью. Прогноз ML показывается для сравнения с расчётом; если сценарий не похож на обучающие, прогноз не выдаётся.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/scenarios` | готовые сценарии, доступность ML, лимиты |
| POST | `/api/forecast` | только проверка и прогноз ML, без расчёта |
| POST | `/api/jobs` | проверка, прогноз и запуск расчёта; возвращает `job_id` |
| GET | `/api/jobs/{id}` | состояние: `running`, `done`, `error`, `timeout` |
| GET | `/api/jobs/{id}/data` | данные для карты |
| GET | `/api/jobs/{id}/result/{strategy}` | результат по контракту 1.0.0 без изменений |
| GET | `/api/sample/{name}` | примеры входных файлов |

Тело `POST`: `{"builtin": "demo"}` или `{"files": {"cargo": "...", "units": "...", "conditions": "...", "config": "...", "geo": "..."}}` — содержимое файлов текстом.

## Настройки (переменные окружения)

- `A3_JOB_TIMEOUT_S` — предел времени расчёта, по умолчанию 900 с; по истечении процесс останавливается;
- `A3_MAX_RUNNING` — сколько расчётов идёт одновременно, по умолчанию 2;
- `A3_MAX_UPLOAD_MB` — предел размера загрузки, по умолчанию 20 МБ;
- `A3_ML_DISABLED=1` — отключить ML; приложение работает и без него.

## Ограничения

- Сервер рассчитан на локальный запуск: слушает `127.0.0.1`, авторизации нет, задания хранятся в памяти и пропадают при перезапуске. Для общего доступа нужны прокси с аутентификацией и постоянное хранилище заданий.
- Объявленные итоги спроса для загруженного сценария выводятся из самого `cargo.csv`, поэтому независимой сверки баланса в этом режиме нет.
- Матмодель считает одну линейную цепочку с одним пунктом назначения. Большие сценарии (сотни рейсов) считаются минутами и могут упереться в предел времени.
- Сообщения проверки входов приходят от матмодели на английском.
