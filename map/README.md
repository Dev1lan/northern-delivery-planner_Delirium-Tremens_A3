# Карта маршрута с графом и нагрузкой

Страница показывает маршрут как граф (пункты — узлы, участки — рёбра), рейсы составов во времени и нагрузку участков. Все числа берутся из результата матмодели по контракту 1.0.0 (`result_adapter.run_scenario` → `result.schema.json`). Страница ничего не рассчитывает сама и не меняет матмодель.

> Данные сценариев синтетические или предположительные. Это не фактический завоз и не система управления судоходством.

## Сборка

Из корня репозитория:

```bash
python map/build_map.py --scenario data/demo/scenario --out map/demo_map.html
```

Получается один HTML-файл без внешних библиотек; открывается двойным щелчком, сеть не нужна.

Параметры:

- `--scenario` — каталог с `cargo.csv`, `units.csv`, `conditions.csv`;
- `--strategies OPTIMIZED EARLIEST_DUE FCFS` — какие стратегии посчитать и показать (первая открывается по умолчанию);
- `--no-ml` — не добавлять прогноз ML; без установленных зависимостей `ml/` карта строится и так;
- `--geo <файл>` — геометрия маршрута; по умолчанию ищется в `map/geo/` по названиям пунктов отправления и назначения;
- `--data-out <файл.json>` — дополнительно сохранить данные карты.

Готовые примеры:

- `demo_map.html` — демо-сценарий (все стратегии дают одинаковый результат);
- `yana_baseline_map.html` — базовый архивный сценарий Яны, оптимизатор заметно лучше простых правил;
- `universal_example_map.html` — синтетический маршрут 208 км из пяти участков (`examples/uni_00567_v0`), где правило «По сроку» довозит в срок больше оптимизатора. Геометрии для него нет, граф показан схемой.

Сгенерированный сценарий можно сохранить в формате проекта функцией `a3_bridge.export_scenario` и передать сборщику вместе с его `config.json` (`--config`).

## Что на странице

- **Граф маршрута.** Узлы и участки — из `config["segments"]`. Цвет участка — проходимость на выбранную дату (полная загрузка, только с недогрузом, не пройти, закрыт) по `conditions.csv` и осадкам флота. Толщина — сколько тонн провезено вверх по участку к этому моменту. Точки — составы: закрашенная идёт с грузом, пустая возвращается.
- **Ползунок времени и «Пуск».** Положение судов считается из `trips[].events` результата.
- **Сравнение стратегий.** Считаются все три стратегии; лучшая определяется по целевой функции матмодели (тоннаж в срок, общий тоннаж, меньше рейсов), помечается «★ лучшая» и открывается по умолчанию. Переключатель показывает граф, рейсы и графики для любой из них.
- **Графики.** Доставка нарастающим итогом против сроков заявок, рейсы по составам, допустимая осадка по дням.
- **Прогноз ML.** Оценка доли в срок до расчёта, интервал и фактический результат расчёта. Если сценарий вне обучающего распределения, показывается отказ от прогноза.

## Геометрия

Русло для карты подбирается автоматически (`geo_resolver.py`):

1. сначала в библиотеке `geo/rivers/*.json` — работает без сети;
2. если реки там нет и задано её название (`--river "Лена"` или поле «Река» в приложении) — запрос в OpenStreetMap; результат упрощается и сохраняется в библиотеку.

Пункты отправления и назначения ищутся по названию среди населённых пунктов у реки, между ними строится путь по руслу. Если название реки не задано, перебираются реки из библиотеки. Вокруг маршрута показываются притоки, берег и ближайшие населённые пункты.

```bash
python map/geo_resolver.py fetch "Лена" "Индигирка"    # пополнить библиотеку
python map/geo_resolver.py list
```

Линия нужна только для отображения: длины участков в расчёте берутся из конфигурации сценария (для Яны 324 км; по линии OSM — около 335 км). Промежуточные узлы ставятся на линию пропорционально расстоянию из конфигурации. `A3_GEO_ONLINE=0` запрещает обращение в сеть.

Если реку найти не удалось, рисуется условное извилистое русло с подписью «Условная схема маршрута». Данные карты: © участники OpenStreetMap, лицензия ODbL.

## Ограничения

- Матмодель считает одну линейную цепочку «пункт отправления → пункт назначения». Поэтому граф сейчас — цепочка, и суммарная нагрузка всех участков к концу навигации одинакова. Сеть с развилками потребует доработки матмодели.
- Проходимость участка на карте — упрощённая подсказка по осадкам флота; фактическую загрузку каждого рейса определяет матмодель.
