# Сеть рек Якутии: карта и сетевой сценарий

Интерфейс к сетевому ядру `network/` 3.0.0 (контракт `result.v3.schema.json`): сеть рек вместо одной цепочки, суда остаются там, где выгрузились, обратная загрузка, порожний перегон к заявкам в других портах и на других реках через море. Ядро не менялось: модуль только готовит входы, запускает `network.adapter.run_scenario` и показывает результат.

> Граф, глубины, флот, заявки и тарифы — синтетические. Координаты портов приближённые, длины участков посчитаны по сглаженным линиям Natural Earth. Это демонстрация механики сети, а не план реальной навигации.

## Запуск

Через приложение (главная страница): `python app/server.py`, затем открыть http://127.0.0.1:8000. Прежняя страница одной реки с прогнозом нейросети — `/yana`.

Автономная страница без сервера:

```bash
python yakutia/payload.py --html yakutia/yakutia_network_map.html
```

## Файлы

| Файл | Что это |
|---|---|
| `geo_build.py` | Геооснова: реки, берег и суша из Natural Earth, порты, участки между портами по руслу, морские переходы. Выход `geo/yakutia_geo.json` |
| `build_scenario.py` | Сценарий для ядра: `data/yakutia/yakutia_network.json`, пределы поиска, демо-тарифы, карточки судов |
| `payload.py` | Запуск четырёх стратегий ядра и сборка данных для страницы; `--results-dir` сохраняет полные результаты v3 |
| `network.html` | Страница: карта сети, шкала времени, вкладки «Обзор», «Суда», «Заявки», «Реки», «Финансы» |

Пересборка геоосновы требует файлов Natural Earth 10m (`ne_10m_rivers_lake_centerlines`, `ne_10m_coastline`) и 50m (`ne_50m_land`) в формате GeoJSON:

```bash
python yakutia/geo_build.py --ne <каталог с файлами>
python yakutia/build_scenario.py
```

## Сценарий «Якутия»

- 24 порта: Лена от Осетрово до Кюсюра и Тикси, Алдан (Хандыга, Эльдикан), Вилюй (Вилюйск, Нюрба), Яна (Батагай, Усть-Куйга, Нижнеянск), Индигирка (Белая Гора, Чокурдах), Колыма (Зырянка, Среднеколымск, Зелёный Мыс). 23 участка, 46 ориентированных рёбер, около 8 000 км сети.
- Морские переходы Тикси → Нижнеянск → Чокурдах → Зелёный Мыс открыты с 20 июля по 25 сентября; реки — по своим окнам навигации с меженью в августе—сентябре.
- Флот: 9 буксиров (речные, мелкосидящие, река—море) и 11 барж с базированием в Осетрово, Якутске, Тикси, Нижнеянске и Зелёном Мысе.
- 17 заявок на 20 400 т: завоз с верхней Лены, перевалка через Якутск и Тикси, арктический завоз на Яну, Индигирку и Колыму, обратный груз с Усть-Куйги.

Результат (пределы поиска из `data/yakutia/limits.json`, все расписания прошли аудит ядра):

| Стратегия | В срок, т | Порожний ход, км | Рейсов | Перегонов | Время |
|---|---|---|---|---|---|
| С перегоном (`NETWORK_REPOSITION`) | 20 400 | 7 886 | 19 | 6 | ~5 с |
| Соцминимумы (`NETWORK_SOCIAL`) | 11 900 | 0 | 11 | 0 | ~2 с |
| По очереди (`NETWORK_FCFS`) | 10 300 | 0 | 11 | 0 | <1 с |
| Жадная (`NETWORK_GREEDY`) | 9 800 | 0 | 10 | 0 | <1 с |

Без перегона суда остаются в порту последней выгрузки, и после первых рейсов флот «застревает». Перегон возвращает их к заявкам, в том числе на соседние реки морем.

## Что показывает страница

- **Карта.** Участки раскрашены по проходимости на выбранную дату для самой глубокосидящей гружёной баржи: полная загрузка, только с недогрузом, закрыт (лёд или нет воды). Морские переходы — пунктир. Подложка под участком тем толще, чем больше тонн по нему уже провезено. Буксиры двигаются по событиям расписания; цвет — этап: погрузка, с грузом, выгрузка, перегон порожним, ожидание, стоит.
- **Суда.** Статус каждого судна на выбранный момент; карточка с характеристиками, занятостью, рейсами и путём за сезон на карте.
- **Заявки.** Сколько выгружено к выбранному моменту, сколько запланировано и успевает ли к сроку; путь заявки на карте.
- **Реки.** Окно навигации, минимальная глубина по реке за сезон против глубины, нужной для полной загрузки, таблица участков на выбранную дату.
- **Финансы.** Оценка `network.financial.evaluate_schedule` по демо-ставкам и натуральные показатели — вход для финансового ядра.

## Ограничения ядра 3.0.0, видимые на карте

- **Класс судна на ребре не проверяется.** В расчёте «С перегоном» речные Т-201, Б-23 и Б-51 выходят в море. Страница помечает такие рейсы как требующие проверки. Нужна доработка ядра: допуск классов судов на ребро.
- Ядро принимает только сценарии с `data_status = "SYNTHETIC"`.
- В одном рейсе одна партия груза; буксир не уходит за баржей отдельно; поиск ограничен пределами (`SEARCH_LIMIT`) и не гарантирует оптимума.
